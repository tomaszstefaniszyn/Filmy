# Filmy do obejrzenia

Statyczna lista filmów serwowana z GitHub Pages (katalog główny gałęzi `main`).

## Jak dodać film

1. Dopisz obiekt filmu na końcu tablicy w `films.json` (tytuł, oryginalny tytuł, gatunek, rok, czas, gdzie oglądać, opis, oceny, link Filmweb, id zwiastunu YouTube oraz pole `img`).
2. Dodaj plakat do katalogu `posters/` i ustaw `img` na względną ścieżkę, np. `posters/tytul.jpg`.
